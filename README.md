# 桌面清单

一个贴在 Windows 桌面层的本地 TodoList 便签。它不会始终置顶，不会遮挡普通窗口，也不会注册开机启动。

## 功能

- 便签停留在 Windows 桌面层，普通窗口始终可以覆盖它。
- 点击输入区域进入编辑模式：窗口获得键盘焦点，并显示在任务栏中。
- 输入中文或英文后按 Enter 新增任务。
- 点击方框完成/恢复任务，底部区域保留已完成任务。
- 切换到其他窗口后，便签自动贴回桌面层。
- 右上角 `×` 只隐藏便签，不结束后台进程。
- 系统托盘图标持续保留：左键调出输入，右键可贴回桌面、隐藏或退出。
- 不联网、不上传任务、不自动启动；任务和窗口位置保存在本机。

## 运行环境

- Windows 10/11
- Node.js 20 或更高版本
- npm

## 开发运行

```powershell
npm install
npm start
```

首次运行时，Windows 可能会询问防火墙或 SmartScreen 权限；这是本地 Electron 应用，不需要网络服务。

## 打包便携版 EXE

```powershell
npm run dist
```

生成文件：

```text
dist/桌面清单-1.0.0-portable.exe
```

这是便携版，不需要安装。双击后会解压到临时目录并启动桌面便签；退出便签后，临时目录由便携启动器管理。

## 使用说明

1. 启动程序后，便签会贴在桌面层。
2. 点击“添加一项任务”输入框，进入可输入模式。
3. 输入内容后按 Enter，或点击“添加”。
4. 点击任务左侧方框标记完成；点击右侧删除按钮移除任务。
5. 点击右上角 `×` 隐藏到托盘。需要继续输入时，点击托盘中的“桌面清单”图标。
6. 右键托盘图标可以选择“贴回桌面”或“退出桌面清单”。

Windows 可能把托盘图标收进任务栏右侧的“^”溢出区域；将图标拖到托盘可见区即可固定显示。

## 数据位置

任务保存在 Electron 的本机用户数据目录中的 `todolist-state.json`。应用不使用云同步，也不会主动访问网络。

## 项目结构

```text
electron/       Electron 主进程、预加载脚本
src/            便签界面和样式
scripts/        Windows 桌面层挂载、图标生成与资源处理脚本
assets/         应用图标和纸张纹理
DESIGN.md       视觉与交互设计说明
PRODUCT.md      产品范围说明
```

桌面层挂载由 `scripts/attach-desktop.ps1` 完成：编辑时窗口临时脱离桌面层以获得可靠的键盘焦点，失去焦点后再贴回桌面层。

## Windows 安全提示

便携 EXE 是本地未签名构建。如果 SmartScreen 显示“Windows 已保护你的电脑”，请确认文件来源后选择“更多信息 → 仍要运行”。
